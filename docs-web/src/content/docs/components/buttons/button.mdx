## Variants

`variant` accepts the keys of your config's [`variants`](/configuration/variants/). These examples use the library defaults: `solid`, `soft`, `outline` and `ghost`.

<Preview>

</Preview>

```tsx
<Button>Solid</Button>
<Button variant="soft">Soft</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
```

## Colors

`color` accepts the keys of your config's [`colors`](/configuration/colors-and-theming/). The text color on each background is computed for contrast in light and dark mode.

## Sizes

`size` accepts the keys allowed for Button in your [`sizes` configuration](/configuration/sizes-and-radii/). A button and an [Input](/components/forms/input/) of the same base size have the same height unless either component overrides it.

<Preview>
<ButtonSizes />
</Preview>

Use `autoHeight` for multiline content such as an account row. The selected size still determines the minimum height, font, icons and padding. This works for both action buttons and links.

```tsx
<Button autoHeight variant="ghost">
  <Avatar name="Ada Lovelace" />
  <Stack gap="xs">
    <Text>Ada Lovelace</Text>
    <Text textStyle="caption" muted>ada@example.com</Text>
  </Stack>
</Button>
```

See the [account menu recipe](/components/overlays/menu/#account-trigger-and-radio-choices).

## Radius

<Preview>

```tsx

```

To make every button square without touching call sites, set a [component default](/configuration/component-defaults/):

```ts
components: { Button: { radius: 'square' } }
```

## With icons

Use `startIcon` or `endIcon` to place a decorative icon beside the label. The icon is sized from the control size's `iconSize`, and the gap follows its horizontal padding. The label supplies the accessible name.

```tsx
<Button startIcon={<CheckIcon />}>Mark complete</Button>
<Button href="/next" endIcon={<ArrowRightIcon />}>Next lesson</Button>
```

Plain `<svg>` children still use the control size's `iconSize`.

## Loading

`loading` shows a [Spinner](/components/feedback/spinner/), disables the button and sets `aria-busy`. The button keeps its height.

<Preview>
  <ButtonLoading client:load />
</Preview>

```tsx
<Button loading={saving} onClick={save}>Save changes</Button>
```

## Accessibility

- Renders a native `<button>` with `type="button"` by default, so it never submits a form by accident. Pass `type="submit"` when it should.
- Disabled buttons use the native `disabled` attribute.
- With `href`, renders a native `<a>` that keeps link semantics, keyboard behavior, and open-in-new-tab support. Pass `target` and `rel` as native anchor props. `loading`, `disabled` and button `type` apply only to the action form.

```tsx
<Button href="/checkout">Enroll in the course</Button>
```

For client-side routing, use the [router link recipe](/getting-started/router-links/).

Without `href`, accepts native `<button>` attributes except `color`. With `href`, accepts native anchor attributes except `color` and button-only props.
