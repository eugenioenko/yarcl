An `IconButton` is as wide as it is tall. It lines up with a [Button](/components/buttons/button/) or [Input](/components/forms/input/) of the same base size unless component size overrides change their heights.

```tsx
<IconButton aria-label="Search" variant="outline">
  <SearchIcon />
</IconButton>
```

## Accessibility

- `aria-label` is **required** by the types: without visible text, it's the button's only name.
- Pair it with a [Tooltip](/components/overlays/tooltip/) so sighted users can see the label too.
- `loading` swaps the icon for a [Spinner](/components/feedback/spinner/) and disables the button.
- With `href`, renders a native link that keeps link semantics and anchor attributes. The link still requires `aria-label`.

```tsx
<IconButton href="/settings" aria-label="Settings"><SettingsIcon /></IconButton>
```

## Props

Without `href`, accepts native `<button>` attributes except `color`. With `href`, accepts native anchor attributes except `color` and button-only props.
