```tsx
  actions={<Button variant="outline">Clear filters</Button>}
/>
```

`gap`, `padding`, `color` and `textStyle` use keys from your config and can be set in `components.EmptyState`. The icon is decorative and receives `color`; the description receives `textStyle`.

## Accessibility

The title is a semantic heading. Set `headingLevel` to fit the surrounding page outline. Empty states are static content and do not announce themselves as live regions. Add a live region separately when an empty state appears in response to an asynchronous action and needs an announcement.

Spacing props accept typed breakpoint maps. See [responsive props](/configuration/responsive-props/) for supported props, defaults and examples.
