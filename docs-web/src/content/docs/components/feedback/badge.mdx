Badges use the same [variant recipes](/configuration/variants/) as buttons. The default is `defaults.softVariant`.

Use `startIcon` or `endIcon` for a decorative status icon. The icon size and the gap from the label follow the badge's size token.

```tsx
<Badge color="success" startIcon={<CheckIcon />}>Completed</Badge>
```

```tsx
<Badge radius="rounded" color="neutral" onRemove={() => remove(tag)} removeLabel={`Remove ${tag}`}>
  {tag}
</Badge>
```

## Long labels

Labels truncate with an ellipsis to stay within their container. The full label remains in the accessible text, and icons and remove buttons keep their space. Use `wrap` for a multiline label, including long words.

```tsx
<Badge>Certified Wonderful Enrichment Educator Graduate</Badge>
<Badge wrap>Certified Wonderful Enrichment Educator Graduate</Badge>
```
