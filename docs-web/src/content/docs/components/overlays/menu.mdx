```tsx
<Menu>

    <Button variant="outline">Actions</Button>
  </Menu.Trigger>
  <Menu.Content>
    <Menu.Item onSelect={rename}>Rename</Menu.Item>

    <Menu.Item color="danger" onSelect={remove}>Delete</Menu.Item>
  </Menu.Content>
</Menu>
```

Use [Select](/components/forms/select/) for a form field. For a setting such as color scheme, use `Menu.RadioGroup` and `Menu.RadioItem`. Each item exposes `role="menuitemradio"` and `aria-checked`, with a check indicator beside the current choice. Choosing an item calls `onValueChange` and closes the menu. Keep the group's `value` in state so it persists when the menu closes.

## Account trigger and radio choices

`Menu.Trigger` accepts a single element that passes through its props and ref. Use `Button autoHeight` for an avatar and two lines of text.

  <AccountMenuDemo client:visible />
</Preview>

```tsx
const [scheme, setScheme] = useState('system');

<Menu>
  <Menu.Trigger>
    <Button autoHeight variant="ghost">
      <Avatar name="Ada Lovelace" />
      <Stack gap="xs">
        <Text>Ada Lovelace</Text>
        <Text textStyle="caption" muted>ada@example.com</Text>
      </Stack>
    </Button>
  </Menu.Trigger>
  <Menu.Content>
    <Menu.RadioGroup aria-label="Color scheme" value={scheme} onValueChange={setScheme}>
      <Menu.RadioItem value="light">Light</Menu.RadioItem>
      <Menu.RadioItem value="dark">Dark</Menu.RadioItem>
      <Menu.RadioItem value="system">System</Menu.RadioItem>
    </Menu.RadioGroup>
  </Menu.Content>
</Menu>
```

Radio items share action items' arrow-key navigation, typeahead, disabled state, and focus return. Give the group a name with `aria-label` or `aria-labelledby`.

For route navigation from a menu action, see the [router link recipe](/getting-started/router-links/).

## Keyboard

| Key | Action |
|---|---|
| <kbd>Enter</kbd> <kbd>Space</kbd> <kbd>↓</kbd> on the trigger | opens the menu and focuses the first item |
| <kbd>↑</kbd> <kbd>↓</kbd> | moves between items, skipping disabled ones |
| typing | jumps to a matching item |
| <kbd>Enter</kbd> <kbd>Space</kbd> | runs the item and closes the menu |
| <kbd>Esc</kbd> | closes; focus returns to the trigger |
