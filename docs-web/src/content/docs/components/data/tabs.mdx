```tsx
  <Tabs.Panel value="activity">…</Tabs.Panel>
</Tabs>
```

Tab height comes from the shared size scale. Pass either `value` (controlled) or `defaultValue` (uncontrolled); the types require one of them.

## Keyboard

| Key | Action |
|---|---|
| <kbd>Tab</kbd> | moves to the selected tab, then into the panel |
| <kbd>←</kbd> <kbd>→</kbd> | selects the previous or next tab, skipping disabled ones |
| <kbd>Home</kbd> <kbd>End</kbd> | selects the first or last tab |
