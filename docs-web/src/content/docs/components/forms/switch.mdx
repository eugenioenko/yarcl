```tsx
<Switch checked={on} onChange={(e) => setOn(e.target.checked)}>Notifications</Switch>
```

A native checkbox with `role="switch"`, so screen readers announce it as on or off, and `checked`, `defaultChecked` and `onChange` work as usual. The track is sized from the size's `iconSize`.

## Props

Accepts every native `<input>` attribute except `type`, `color` and `size`.
