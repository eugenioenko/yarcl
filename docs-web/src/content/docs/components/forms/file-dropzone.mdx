```tsx
import { FileDropzone } from '@yarcl/react';

<FileDropzone
  label="Attachments"
  description="Images or PDF files"
  accept="image/*,.pdf"
  multiple
  onFilesChange={(files) => upload(files)}
/>
```

The button opens the native file picker. Files can also be dropped on the bordered area. `accept` filters dropped files as well as picker selections. `multiple` shows a file list with remove buttons. Use the render prop to provide your own list:

```tsx
<FileDropzone label="Attachments" multiple>
  {(files, removeFile) => (
    <ul>
      {files.map((file, index) => (
        <li key={`${file.name}-${index}`}>
          {file.name}
          <button type="button" onClick={() => removeFile(index)}>Remove</button>
        </li>
      ))}
    </ul>
  )}
</FileDropzone>
```

Use `onFilesChange` to upload or validate the selected files. Upload progress belongs to the upload request, so render it beside this component.

## Single file and image preview

Without `multiple`, the dropzone shows one current file with Replace and Remove controls. Pass `preview` to show a thumbnail for a selected image. Use `value` with `onChange` for a controlled picker, or `defaultValue` for an uncontrolled initial file.

```tsx
const [cover, setCover] = useState<File | null>(null);

<FileDropzone
  label="Course cover"
  accept="image/*"
  value={cover}
  onChange={setCover}
  preview
/>
```

For an existing image hosted by your app, pass `previewUrl` and `previewName`. Clear the URL in your `onChange` handler when the user replaces or removes it:

```tsx
<FileDropzone
  label="Course cover"
  accept="image/*"
  value={cover}
  onChange={(file) => { setCover(file); setCoverUrl(undefined); }}
  preview
  previewUrl={coverUrl}
  previewName="Current cover"
/>
```

`onFilesChange` still receives an array in either mode for existing upload handlers. In single-file mode, `onChange` receives the file or `null` after removal.
