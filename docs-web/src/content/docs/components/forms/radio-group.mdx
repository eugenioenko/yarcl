```tsx
<RadioGroup label="Plan" value={plan} onValueChange={setPlan} orientation="horizontal">
  <Radio value="free">Free</Radio>
  <Radio value="pro">Pro</Radio>
  <Radio value="team">Team</Radio>
</RadioGroup>
```

`RadioGroup` renders a `<fieldset>` with a `<legend>`, gives the radios a shared `name`, and tracks the selected value. Radios inside don't need `name` or `checked`. Like [Field](/components/forms/field/), it takes `description` and `error`.

Native radio keyboard behavior applies: <kbd>Tab</kbd> moves into the group, arrow keys change the selection.
