```tsx
<Input disabled />
```

- `size` sets the height, padding and font size. An input and a [Button](/components/buttons/button/) of the same size have the same height.
- `color` sets the focus border and ring.
- Inside a [Field](/components/forms/field/) it's labelled, described and marked invalid automatically.

## Props

Accepts every native `<input>` attribute except `color` and `size`, which are replaced by design tokens.
