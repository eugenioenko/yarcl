```tsx
<Field label="Guests" description="Between 1 and 12 people.">
  <NumberInput min={1} max={12} defaultValue={2} />
</Field>

<Field label="Price">
  <NumberInput value={price} onValueChange={setPrice} min={0} step={0.5} />
</Field>
```

- The value is a `number`, or `null` when the input is empty. Use `value` and `onValueChange` to control it, or `defaultValue` to leave it uncontrolled.
- Typed text is committed on blur or `Enter`: it's clamped to `min` and `max`, and text that isn't a number reverts to the last value.
- `size`, `radius` and `color` work like [Input](/components/forms/input/): a number input and an input of the same size have the same height, and `color` sets the focus border and ring. Defaults come from `components.NumberInput`, then `defaults`.
- Inside a [Field](/components/forms/field/) it's labelled, described and marked invalid automatically.

## Accessibility

- The input has the `spinbutton` role with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.
- `ArrowUp` and `ArrowDown` step by `step`, `PageUp` and `PageDown` by ten steps, and `Home` and `End` jump to `min` and `max`.
- The stepper buttons are labelled (`incrementLabel`, `decrementLabel`) and left out of the tab order, since the arrow keys do the same. Clicking them keeps focus where it was.

## Props

Accepts every native `<input>` attribute except `color`, `size`, `type`, `value`, `defaultValue`, `onChange`, `min`, `max` and `step`, which are replaced by the props below. `className` and `style` apply to the outer box; everything else goes to the input.
