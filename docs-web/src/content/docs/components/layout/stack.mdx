```tsx
<Stack gap="md">
  <Heading level={2}>Profile</Heading>
  <Field label="Name"><Input /></Field>
</Stack>
```

`gap` accepts the keys of your [spacing](/configuration/spacing-shadows-density/) and defaults to `defaults.gap`. Use `as` to render a semantic element (`section`, `form`, `ul`, `nav` …); list styles are reset.

## Props

Accepts every native `<div>` attribute.
