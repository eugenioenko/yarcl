```tsx
<Inline justify="between">
  <Text>Title</Text>
  <Inline gap="sm">
    <Button variant="outline">Cancel</Button>
    <Button>Save</Button>
  </Inline>
</Inline>
```

Children are centered vertically and wrap by default. Set `wrap={false}` to keep them on one line.

Spacing props accept typed breakpoint maps. See [responsive props](/configuration/responsive-props/) for supported props, defaults and examples.
